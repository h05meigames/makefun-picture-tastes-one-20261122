A program that renders one big, glossy, ripe strawberry — a single-ingredient food picture — procedurally in code and writes it to `/output/entry.png`. One close-up hero strawberry on a dark moody background with a soft spotlight: radial-gradient shading, specular gloss, water droplets, seed dimples and green calyx leaves, all computed in the program with Node built-ins only. Deterministic: two runs produce byte-identical output.

## Run it

```sh
node main.ts
```
